## ✨ 游戏特色 (Game Highlights)

灵感源自经典物理益智神作 **《小鳄鱼爱洗澡》(Where's My Water?)**，由 **Smiling Critters (微笑萌宠)** 全员担任主角！每一关都有一只浑身沾满泥巴的萌宠坐在右下角的泡泡浴缸里等你引水洗澡：

1. **⛏️ 像素级丝滑挖土与岩石物理导流**
   - 在棕色泥土上按住鼠标左键或手指拖动，即可实时挖出光滑圆润的地下水道。
   - 灰色岩石斜坡不可挖掘，可巧妙利用石板坡面引导水流方向。

2. **🧪 四大经典流体与物态相克系统**
   - **💧 清澈洗澡水 (Clean Water)**：受重力与流体压强驱动，淋满沿途的 **3 只萌宠小黄鸭 (`🐤×3`)** 并流进右下角 **浴缸漏斗 (`🚿`)** 满 25 滴即可通关！
   - **🧪 噩梦紫毒水 (Toxic Ooze)**：触碰清水会将其感染变毒；但**毒水遇到绿藻会相互反应，把堵路的绿藻彻底腐蚀清除**！
   - **🌿 吸水绿藻苔藓 (Green Algae)**：喝到清水会疯狂生长堵死隧道，需用毒水腐蚀或使用「✨ 净水除苔」铲除。
   - **🔥 炙热炭火 & ❄️ 寒冰冷凝 (Hot Coals & Ice Condenser)**：水滴落到红热炭火上会瞬间沸腾化作 **💨 上升水蒸气** 飘过障碍，接触顶棚寒冰后重新凝结成 **💧 清澈水滴** 落下！

3. **🔔 彩色开关、滑动闸门与高压水龙头**
   - 水流冲击 **🔴🔵🟢🟣 铃铛开关** 即可自动移开对应颜色的铁闸门；部分关卡配有持续喷水的 **🚰 高压水龙头**。

4. **💡 贴心辅助工具栏（零卡关友好设计）**
   - `⛏️ 挖土开路` / `🧱 填土堵漏` / `✨ 净水除苔` / `🌧️ 加水喷头 (+45滴)` / `💡 一键挖通提示` / `🔄 重玩本关`
